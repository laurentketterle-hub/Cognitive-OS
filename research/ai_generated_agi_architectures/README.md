## Overview

This packet contains AGI architecture proposals generated by ten frontier AI systems, along with structured comparison and synthesis. The research was conducted as part of the Cognitive-OS $3,000 bounty for AGI architecture exploration.

The goal was to understand how today's most capable AI systems envision the path to AGI — what architectural patterns they converge on, what they diverge on, and what insights can be extracted for real-world AGI development.

### Architectural Dimensions Covered

Each proposal addresses nine standardised dimensions:

1. **Core Architecture** — High-level system design
2. **Learning Mechanism** — How the system continuously learns
3. **Knowledge Representation** — Information storage and retrieval
4. **Memory Systems** — Working, episodic, semantic, and procedural memory
5. **Reasoning Engine** — Deductive, inductive, and abductive reasoning
6. **Safety & Alignment** — Beneficial behaviour guarantees
7. **Scalability** — Scaling with compute and data
8. **Key Innovation** — The novel insight enabling AGI
9. **Estimated Timeline** — When the architecture could be realised

---

## Key Findings (Quick Summary)

1. **Hybrid architectures are universal** — 10/10 proposals combine multiple approaches (no pure neural or symbolic AGI)
2. **Memory is architecture** — every proposal has 3+ distinct memory systems with consolidation mechanisms
3. **Continuous learning is mandatory** — the frozen-model paradigm is unanimously rejected for AGI
4. **Safety must be architectural** — post-hoc filters are seen as inadequate at AGI scale
5. **Metacognition is emerging as critical** — 7/10 proposals include self-modelling components
6. **Timeline consensus: 2030–2035** — median AGI estimate across all proposals is ~2033
7. **Formal verification is the frontier** — only one proposal pursues mathematical safety proofs, representing an underexplored approach

*Full synthesis with analysis and implications: [`summary.md`](summary.md)*

## Methodology

All ten systems were queried between July 29–31, 2026 using a standardised base prompt (see [`prompts.md`](prompts.md)). Adaptations were made only for system-specific constraints (e.g., Grok-2 was told it had real-time data access; Perplexity was asked to search and synthesise). Each system was queried independently in a fresh session. Raw outputs were minimally cleaned — conversational artifacts removed, technical content preserved.

### Systems Represented

- **3 US labs:** OpenAI, Anthropic (2 systems), xAI
- **1 US large tech:** Google DeepMind, Meta
- **2 Chinese labs:** DeepSeek, Alibaba (Qwen)
- **1 French lab:** Mistral AI
- **1 Search-native:** Perplexity
